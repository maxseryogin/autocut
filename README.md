# autocut — Splitclip

Мини-студия: импорт TikTok или видеофайла, кадрирование камеры, собственный видеофон, субтитры и рекламный видеобаннер с хромакеем. Экспорт — вертикальный MP4 или WebM в зависимости от браузера.

## Запуск

Нужны Python 3.10+, FFmpeg в PATH и доступ к сети для импорта TikTok. В Windows установите зависимости: `py -3 -m pip install -r requirements.txt`, затем запустите `start.bat` или `py -3 app.py`. Откройте http://127.0.0.1:8765 в Chrome или Edge. При первом распознавании субтитров приложение загрузит модель Whisper; локальные модели и видео в репозиторий не входят.

Для автопоиска OpenCV анализирует несколько кадров, ищет лицо и устойчивые границы окна камеры. Если чёткие границы не найдены, область оценивается по лицу. Проверьте рамку в разделе «Поправить границы камеры» и при необходимости нарисуйте её заново; в предпросмотр и экспорт попадут только пиксели внутри рамки. Если лицо не найдено, рамку необходимо выбрать вручную. Фоновое видео следует за исходным роликом при воспроизведении, паузе и перемотке. Импорт зависит от доступности TikTok и актуальности yt-dlp; при необходимости обновите пакет командой `py -3 -m pip install --upgrade yt-dlp` или загрузите видеофайл вручную. Если используется локальная копия `vendor_ytdlp`, обновлять нужно её: `py -3 -m pip install --upgrade --target vendor_ytdlp yt-dlp`. Запись идёт в реальном времени; звук берётся из исходного видео, если браузер поддерживает captureStream аудиодорожки.

Субтитры создаются автоматически локальным faster-whisper из звука исходного ролика и показываются по одному слову. По умолчанию выбран русский язык; можно выбрать украинский, английский или автоматическое определение. Более точная модель medium при первом запуске скачивается в папку `models` (около 1,5 ГБ). Распознавание на процессоре может занять несколько минут. В разделе субтитров можно отключить их, перезапустить распознавание и исправить текст. Субтитры встраиваются в итоговое видео; отдельный файл субтитров не создаётся.

Фоновое видео необязательно: без него исходный ролик показывается целиком с лёгкой цветокоррекцией, а при выборе фона используется раздельная компоновка с камерой сверху. Цветокоррекция сама по себе не гарантирует защиту от претензий правообладателей. Можно также выбрать рекламный видеобаннер с зелёным фоном. Приложение предлагает момент вставки по паузам и изменению громкости в средней части исходника; это приблизительный ориентир, а не распознавание смысла. Момент и чувствительность хромакея можно изменить вручную. Во время баннера исходное и фоновое видео стоят на паузе, затем продолжаются. Экспорт включает звуковые дорожки исходника и баннера, если браузер поддерживает Web Audio. Для проверки на большом экране используйте кнопку ⛶ в предпросмотре.

Блок «Проверка условий» оценивает длительность исходника без рекламы, наличие звука баннера, время первой вставки и частоту повторов. Баннер используется целиком независимо от его длительности. При ролике длиннее минуты баннер повторяется на каждой следующей начатой минуте. Размер и положение подбираются автоматически по выборке кадров после хромакея; если полностью сохранить пропорции и достичь нужного размера невозможно, высота может быть немного изменена. Проверяйте всю анимацию и читаемость вручную: выборка не доказывает соответствие каждого кадра, а если в исходном баннере анимация в отдельные моменты слишком мала, без изменения содержимого гарантировать размер нельзя. Для исходников 10–20 секунд применяется условие первой половины; для более длинных — 10–15 секунд и первая половина. Приложение не проверяет публикацию или просмотры.

Звук исходника и баннера локально измеряется через FFmpeg (средняя интегральная громкость), затем оба приводятся к ориентиру −16 LUFS, а общие пики ограничиваются в Web Audio. Усиление ограничено 15 дБ; на шумных или сильно сжатых записях итог может субъективно различаться, поэтому проверьте результат на слух. Готовые файлы и оригинальный баннер не изменяются.

По умолчанию предпросмотр и экспорт работают в Full HD (1080×1920, 30 кадров/с), баннер обрабатывается в том же разрешении без промежуточного уменьшения. Если компьютер не успевает обрабатывать видео, выберите HD (720×1280) в настройке качества. Более высокое разрешение не восстанавливает детали, которых нет в исходном видео.

Подготовленная конфигурация для виртуальной машины с Docker, HTTPS и общим паролем описана в [deploy/README.md](deploy/README.md). Она ещё не развёрнута и не проверена на Oracle Cloud или конкретных телефонах.

## Упаковка в exe

Приложение можно попробовать упаковать с PyInstaller после установки `pyinstaller`: `py -m PyInstaller --noconfirm --onedir --add-data "static;static" --paths vendor4 --paths vendor_ytdlp --collect-all cv2 --collect-all yt_dlp --collect-all faster_whisper --collect-all ctranslate2 --collect-all av app.py`. Запускайте `dist\app\app.exe`. Сборка ещё не проверена; для отдельного окна понадобится дополнительно встроить WebView. Загруженные видео хранятся во временной папке системы; экспорт скачивается через браузер.
